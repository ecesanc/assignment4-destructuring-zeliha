Abbreviations and Key Terms
AI: Artificial Intelligence, as in AI coding assistants.
children: A special prop. Whatever you write between the opening and closing tags of a component, <Card>this</Card>, arrives in the component as props.children.
default value: A value used when the item is missing (undefined): const { size = 10 } = options.
destructuring: Taking values out of an array or an object into separate variables with one pattern on the left: const [x, y] = f() or let { a, b } = t.
JSX: The HTML-like syntax inside JavaScript and TypeScript files that React turns into function calls.
LaTeX: A typesetting system for documents with a lot of structure and code. The source is plain text and the output is a PDF.
Moodle: The course platform: you download materials and upload assignments there.
pattern: The left side of a destructuring: the shape you describe, such as [first, ...rest] or { a, b }.
props: The single object a React component receives. Its fields are the attributes you write in JSX.
rest: The ...name in a pattern that collects what is left over into a new array or object.
spread: The ...value in an expression that expands an array or object into separate items or fields. It looks like rest but does the opposite job.
TS: TypeScript, JavaScript with static types.
tuple: A TypeScript array type with a fixed length and a type for each position, such as [number, string].

The twelve forms

Form	Pattern	Group

Your job is to separate the two ideas, props and children, and to show that you understand the difference, not only the syntax.

How an entry looks

README.md

### Form 6: rename while you take it, `const { title: heading } = task`

**Syntax:** `const { title: heading } = task`

**Example** (from `js/objects.mjs`, my own data):

```js
const book = { title: 'Dune', year: 1965 }
const { title: name } = book
console.log(name)
```

**Output:** `Dune`

**Use it when:** the property name clashes with a variable you already have,
or the name is not clear in this place.

**Watch out:** the old name is NOT a variable after this. `title` does not exist here,
only `name` does. (Reading it as "title becomes name" is what makes it easy to remember:
the source is on the left of the colon and the new name is on the right.)

Troubleshooting
What you see	Why, and what to do
TypeError: Cannot destructure property 'a' of 'undefined'	The value on the right is undefined or null. Give the parameter a default (= {}) or check the value first.
SyntaxError on { a } = obj	A line that starts with { is read as a block. Write ({ a } = obj) with parentheses, or use const.
A variable is undefined although the field exists	You may have renamed it: in { a: b } the variable is b, and a does not exist.
ReferenceError: React is not defined	The JSX setting is missing. Keep jsx: "react-jsx" in tsconfig.json and run the file with npx tsx.
Object is possibly 'undefined' after const [first] = items	noUncheckedIndexedAccess is on, so an array item may be missing. Check it, or give it a default.
Property 'children' does not exist on type	Your props type does not list children. Add children?: ReactNode or use PropsWithChildren.
